# Единый кабинет аудитора SAQ

Интерактивный прототип рабочего места внутреннего сотрудника Smart Audit Qazaqstan. С рабочего стола можно перейти к порученному документу, его сроку, своему мероприятию или доступному модулю.

## Что посмотреть

Главная страница открывается в демонстрационной сессии согласующего А. Садыкова. В меню профиля справа доступны другие сотрудники и выход. Маршрут `/#/login` показывает вход с тестовыми логином и паролем. Для каждого профиля реквизиты предзаполнены. Повторный показ с текущей даты можно запустить через «Демонстрационный стенд» → «Начать демонстрацию заново».

| Сотрудник | Сценарий |
| --- | --- |
| Согласующий | Открыть «Просрочено», перейти к запросу материалов ВОЗ-2026-027. Из рабочего стола открыть программу ВГА-2026-041, посмотреть печатную форму, согласовать и вернуться в ЕКА. |
| Утверждающий | После согласования программы в предыдущем сценарии открыть поступившее поручение на утверждение. До активации этап виден отдельно в ожидающих. |
| Аудитор-инициатор | Увидеть возврат отчёта, решение по возражению и ответ объекта. В отправленных документах проверить адресата и состояние каждого этапа. |
| Аудитор СВА | Открыть назначенный объект своего мероприятия и увидеть даты начала и окончания в календаре. |
| Специалист по перечню | Открыть региональный пакет СУР-2026-010 и указать решения по объектам. |
| Член комиссии | Увидеть в календаре срок подтверждения участия и отдельное событие самого заседания. |
| Сотрудник на обучении | Открыть свои назначения, срок курса и прогресс по урокам и итоговому тесту. |
| Кадровая служба | В разделе «Коллектив» скачать образец CSV и загрузить ФИО, день и месяц. Ближайшие дни рождения появятся на рабочих столах внутренних демопрофилей этого браузера. |

Счётчики рассчитываются из выведенных записей. «Срок сегодня» включает поручения с датой исполнения в текущем дне по времени Астаны, в том числе те, срок которых уже истёк сегодня. «Просрочено» учитывает точное время. Перечни, сроки и данные о ходе аудита сохраняют принадлежность исходному модулю.

## Демонстрационное окружение

ЕКА использует локальную копию модели общих поручений. Решение в форме документа обновляет очередь, историю и следующий этап внутри этого экземпляра прототипа. Обучение и мероприятия представлены снимками тестовых данных. Переход к курсу или объекту открывает соответствующий внешний стенд.

Данные общих поручений и импортированный список сохраняются в браузере. Профиль входа действует в текущей вкладке. На рабочем контуре источниками прав и записей должны стать SAQ ID и серверные сервисы модулей. Изменений в авторизации портала и в действующих модулях SAQ этот прототип не вносит.

## Запуск

Node.js 22+ для сборки и проверки. Сторонние пакеты устанавливать не требуется.

```sh
npm test
npm run build
npm run dev
```

Локальный адрес — http://localhost:4173. Для Vercel каталог публикации — `dist`.
