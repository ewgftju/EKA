# Единый кабинет аудитора SAQ

Интерактивный прототип рабочего места внутреннего сотрудника Smart Audit Qazaqstan. [Открыть кабинет](https://saq-eka.vercel.app/)

## Что посмотреть

При первом открытии выбран руководитель группы аудита Жукенов Каримжан Амангельдыевич. В следующем посещении той же вкладки сохраняется выбранный сотрудник. Меню профиля справа позволяет переключать участников и выходить из кабинета. На странице входа реквизиты тестового профиля предзаполнены.

| Профиль | Сценарий |
| --- | --- |
| [Руководитель группы аудита](https://saq-eka.vercel.app/#/login?profile=auditor) | Открыть «Мои дела». На рабочем столе видны текущие этапы ВГА и СВА. В реестре можно выбрать модуль, найти начатые или завершённые дела, посмотреть свою роль и открыть исходную карточку. «Созданные мной» отбирает дела с подтверждённым автором. |
| [Согласующий](https://saq-eka.vercel.app/#/login?profile=reviewer) | Открыть «Согласовать программу аудита» ВГА-2026-041, изучить печатную форму и принять решение. Срок этого поручения в модуле не задан. |
| Утверждающий | После согласования программы открыть «Утвердить программу аудита». До активации шаг виден в ожидающих. |
| Аудитор-инициатор | Открыть возвращённый аудиторский отчёт. В отправленных проверить статус и адресата своего документа. |
| Государственный аудитор 12 | Открыть проект СВА-260006 в группе «Ещё не начаты» или перейти к объекту через календарь. |
| Специалист по перечню | Открыть региональный пакет СУР-2026-010 и указать решения по объектам. |
| Член комиссии | Открыть заседание из календаря. Участнику отдельно поручено подтвердить присутствие. |
| Сотрудник на обучении | Открыть свои назначения, срок курса и прогресс по урокам и итоговому тесту. |
| Кадровая служба | В разделе «Коллектив» скачать образец CSV и загрузить ФИО, день и месяц. Ближайшие дни рождения появятся на рабочих столах внутренних демопрофилей этого браузера. |

## Демонстрационное окружение

Дела и обучение представлены снимками тестовых данных. Демоучётки одного и того же аудитора ВГА и СВА сопоставлены явно. В новом профиле Жукенова 10 дел в работе, 5 ещё не начаты и 8 завершены. Адресованные другим сотрудникам документы доступны под их собственными демопрофилями.

ЕКА использует локальную копию общей модели поручений. Решение в форме документа обновляет очередь, историю и следующий этап. Прежние относительные сроки общего макета убраны. При первом открытии обновления кабинет корректирует старые примеры, сохраняя принятые решения, изменения документов и прочтения. Данные хранятся в браузере. Через «Демонстрационный стенд» → «Начать демонстрацию заново» можно восстановить исходные примеры.

Карточка дела или курса открывается на отдельном стенде соответствующего модуля с его собственной демосессией. Для рабочего контура права и записи должны поступать из SAQ ID и серверных сервисов модулей.

## Запуск

Node.js 22+ используется для сборки и проверки. Сборка работает без установки сторонних пакетов.

```sh
npm test
npm run build
npm run dev
```

Локальный адрес — http://localhost:4173. Для Vercel каталог публикации — `dist`.
